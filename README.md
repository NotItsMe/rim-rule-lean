# rim_rule

Lean 4 + mathlib formalization of Theorem 1 (the Rim rule) for neural codes, and of
70 counterexamples to Conjecture 3.13 of Gambacini, Jeffs, Macdonald, Shiu (arXiv 1912.00963).
That conjecture says every locally good code on at most 7 neurons is open-convex or
closed-convex.

## Verdict

`RimRule.conj313_counterexample` proves, with only the standard axioms
`[propext, Classical.choice, Quot.sound]`, that there is a code on 7 neurons that is a neural
code, satisfies `LocallyGoodC`, and is neither open-convex nor closed-convex.
`RimRule.Rim70.all70_spec` proves the same for each of 70 distinct codes.

The result relies on exactly **one** cited fact that is not proved in Lean:
**collapsible ⇒ contractible** (a textbook fact of combinatorial topology). `LocallyGoodC C`
says every nonempty non-codeword face of Δ(C) has a collapsible link; with that fact it is the
definition of "locally good" (1912.00963, Def 2.14–2.15).

See `LEAN_FINAL.md` for the exact statements, the build and the axiom check.

## Build

```
lake build                 # about 20 min; the Rim70 certificate files are the slow part
lake env lean Check.lean   # prints the main statements and their axioms
```

The files under `RimRule/Rim70/` are generated by `scripts/gen_rim70.py` from
`data/rim70.json`. The script only finds collapse certificates; Lean re-checks everything.
