# LEAN_FINAL: what Lean proves about the Conjecture 3.13 counterexamples

Date: 2026-11-22. Lean 4.36.0, mathlib `fc4f59e`. Repo: `NotItsMe/rim-rule-lean`.

## In plain words

Gambacini, Jeffs, Macdonald and Shiu (arXiv 1912.00963) made a guess, **Conjecture 3.13**: every
"locally good" neural code on at most 7 neurons can be drawn with convex shapes that are all open,
or all closed. We have 70 codes on 7 neurons that break that guess.

For each of the 70 codes, Lean (a program that checks every step of a proof) confirms:
1. it is a neural code (the empty word is in it);
2. it can't be drawn with open convex shapes, or with closed convex shapes (Theorem 1);
3. every "missing" face of the code has a link that can be squashed down to a single point,
   one legal move at a time ("collapsible").

To get from 3 to "locally good" you need one fact that Lean does not check: **a shape that can
be squashed to a point this way is contractible** (has no holes). This is a standard textbook
fact. Lean can't state it yet, because mathlib has no way to turn these lists of sets into
actual geometric shapes. **That is the only thing taken on trust.** Everything else is checked
by Lean, using only the three standard background rules every mathlib proof uses.

What changed this session: before, "locally good" needed **two** facts on trust. The second one,
from Curto et al., said the faces we skipped were fine. Now Lean proves that itself (the cone
lemma below), so there are no skipped faces and only one cited fact is left.

## The headline theorem

`RimRule/Conj313.lean`:

```lean
theorem conj313_counterexample :
    ∃ C : Finset (Finset (Fin 7)),
      IsNeuralCode C ∧ LocallyGoodC C ∧ ¬ IsOpenConvex C ∧ ¬ IsClosedConvex C
```

Docstring: refutes Conjecture 3.13 of Gambacini–Jeffs–Macdonald–Shiu (arXiv 1912.00963), modulo
the single cited fact collapsible ⇒ contractible. The witness is `Rim70.FiveFac399`.

`RimRule/LocallyGood.lean`:

```lean
/-- every nonempty face of Δ(C) that is not a codeword has a collapsible link -/
def LocallyGoodC (C : Finset (Finset (Fin n))) : Prop :=
  ∀ σ ∈ delta C, σ.Nonempty → σ ∉ C → Collapsible (link (delta C) σ)

-- a cone (adding the apex v to any face gives a face) collapses to its apex
theorem collapsible_of_cone (v : Fin n) (K : Finset (Finset (Fin n))) :
    IsComplex K → ∅ ∈ K → IsConeWith K v → ∃ steps, CollapsesTo K steps {∅, {v}}

-- if σ is not its own hull, its link is a cone, hence collapsible
theorem collapsible_link_of_hull_ne (hΔ : σ ∈ delta C) (h : hull C σ ≠ σ) :
    Collapsible (link (delta C) σ)

-- a kernel-checked certificate (for the faces equal to their hull) gives LocallyGoodC
theorem locallyGoodC_of_certOK (h : CertOK C cert) : LocallyGoodC C

theorem LocallyGoodC.linksCollapsible (h : LocallyGoodC C) : LinksCollapsible C
```

## The one cited fact

**Collapsible ⇒ contractible.** An elementary collapse is a deformation retraction, so a
simplicial complex that collapses to a single vertex is contractible. With it, `LocallyGoodC C`
says exactly that every nonempty `σ ∈ Δ(C) ∖ C` has a contractible link, which is "locally good"
in 1912.00963 Def 2.14–2.15.

## How the 1,410 missing faces are covered

Across the 70 codes there are 1,410 nonempty faces of Δ(C) that are not codewords (recounted in
Python; matches DEF_CHECK.md).
- **278 faces equal their hull** (the intersections of maximal codewords). Each has an explicit
  collapse sequence, generated by `scripts/gen_rim70.py` and checked by `decide +kernel`
  (not `native_decide`). These certificates are unchanged from Stage 8.
- **1,132 faces don't equal their hull.** Some neuron `v ∉ σ` lies in every maximal codeword
  containing σ, so the link is a cone with apex `v`. Instead of 1,132 more certificates (far too
  slow: the 278 already take about 14 min of kernel time), `collapsible_of_cone` proves once, for
  every cone, that it collapses. `LocallyGoodC` asks about every face, so nothing is skipped.
